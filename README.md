## 2. Sobre o projeto

Este projeto foi desenvolvido como atividade acadêmica, com o objetivo de aplicar os conhecimentos adquiridos durante as aulas e desenvolver uma aplicação com navegação intuitiva e
interação com o usuário.

## 3. Público-alvo

O site foi desenvolvido pensando em usuários que necessitam de uma interface simples, organizada e de fácil utilização.

## 4. Planejamento e referências

Durante o planejamento, foram consideradas as necessidades do público-alvo, a organização das informações, a facilidade de navegação e a identidade visual do projeto.

As decisões de desenvolvimento foram tomadas considerando:
- Organização e clareza do conteúdo.
- Facilidade de navegação.
- Identidade visual consistente.
- Responsividade da interface.

## 5. Navegação

A navegação foi organizada para permitir que o usuário acesse as funcionalidades de maneira simples e intuitiva.

## 6. Como executar o projeto

1. Baixe ou clone os arquivos do projeto.
2. Extraia a pasta.
3. Abra a pasta no Visual Studio Code.
4. Execute o projeto conforme as tecnologias utilizadas.

## 7. Interação adicional

O projeto apresenta uma funcionalidade interativa adicional: menu responsivo, filtro de busca por categoria, validação dos campos de login e senha e contagem de itens no carrinho.

## 8. Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- lucide icons.
